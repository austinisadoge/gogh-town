# 畫家個人塗鴉

十二張原創塗鴉海報，讓每位畫家有自己的簽名式。每一張都把一個大母題、自己的構圖，和一句嗆對手的短句，跟那位畫家生涯裡的某件作品、主題或技法綁在一起。**所有標語都是新寫的遊戲台詞**，符號、字體和恩怨都是虛構的，不是歷史上畫家的真實簽名或語錄。

牆上的完整塗鴉用的是 **512 × 512 的細緻 SVG**。另外一組 **256 × 256 的精簡徽章** 負責介面圖示、武器標記和擊殺印章，縮小了也看得清楚。兩種版本共用同一組畫家代號與配色。

## 中文版的排字規則

中文是方塊字，跟 Impact 這種窄體的比例完全不同。`src/art-tags.js` 的 `lettering()` 做了兩件事：

1. **字級縮到 0.85 倍。** 同樣的 font-size，Impact 的字高只有約 0.72 em，中文字卻佔到 0.86 em。不縮的話中文會比原本的英文高一截，直接壓到上面那一行。
2. **不硬拉字身。** 原本用 `lengthAdjust="spacingAndGlyphs"` 把字拉滿版位寬度，中文套上去會被壓扁，所以改成只調字距。

還有一條改字時要遵守的比例：**一個版位能放的中文字數 ≈ 原本的英文字母數 × 0.45**。想改標語的話先照這個算，字太多會爆框。

## 執行時的規則

- 按 **T** 會把選中畫家的塗鴉噴在附近的牆上，**冷卻 4 秒**。噴漆會貼合表面，圖案依幾何裁切。
- 擊殺時會短暫顯示成功那一方畫家的小型個人印章。電腦對手也偶爾會在戰鬥空檔噴塗鴉。
- 這些純粹是表現性的裝飾動作。**不會加血、沒有養成、沒有計數器，也不另外計分。**

牆上的塗鴉把文字整合進構圖，並用大塊的對比形狀。小印章用的是只有母題、沒有文字的 SVG。秀拉的點描太陽和席涅克的點描帆一眼就分得出來，舞鞋和海報舞者、兩張有樹的設計也一樣。

## 素材 API

`getArtistTag(artist)` 保留 `id`、`artist`、`name`、`palette` 和完整的 `svg`，另外加上 `taunt`、`compactSVG` 以及它的別名 `stampSVG`。`tagDataURI(artist)` 預設回傳牆上的完整塗鴉；小型介面標記用 `tagDataURI(artist, 'compact')`，擊殺特效用 `'stamp'`。SVG 的文字有明確寬度，並帶本機系統字型的後備清單（含繁體中文字型）。**沒有任何外部字型、圖片或濾鏡的相依。**

這些圖像都是在本機畫出來的原創詮釋。博物館的圖片只是研究參考，沒有被下載、描摹，也沒有打包成塗鴉貼圖。暫時的貼花和印章是遊戲效果；原始地圖、小鎮畫面和保留的參考檔都維持原樣。**本專案不代表任何博物館的背書。**
