# 貝爾特・莫利索 · 1888 年底 47 歲

莫利索有一張成熟的長臉，身形輕盈挺拔。緊湊的軟帽、窄身的高領軀幹和貼身垂落的披肩，構成三個遊戲距離下的辨識點。軟帽周圍露出灰色的波浪髮。束起的袖口保住輕盈的肩線；**卡薩特那邊則維持較寬的臉、較豐厚的身形和往外延伸的大禮帽，兩人要分得開。**

[瑪摩丹莫內美術館的館藏](https://www.marmottan.fr/collections/berthe-morisot/) 標定了她的 **1885 年自畫像**。複製圖在該館的[2023 年資料冊第 18 頁](https://www.marmottan.fr/wp-content/uploads/2023/04/B18-DP_BAT-pages.pdf#page=18) 實際檢視過。三個臉部線索指引了雕塑：中分的灰色波浪髮框住鬢角；下收成小下巴的長橢圓臉；窄鼻與收斂的嘴之上輪廓分明的眼皮。臉頰量體和帶年齡感的眼皮讓她維持成熟女性的樣貌，**不要做成瘦削年輕的娃娃臉**。

也開啟並實際檢視了[馬內 1872 年在奧賽美術館的肖像](https://www.musee-orsay.fr/en/artworks/berthe-morisot-au-bouquet-de-violettes-100102)。那是下臉和高領口的較早比對，**不是年齡的樣板**。奧賽指出她的眼睛其實是綠色的，儘管畫裡描繪成黑色。選用的綠色和所有膚色都是繪畫式近似。

緊湊的緞帶軟帽、石板色羊毛外套、象牙色領子、銀灰披肩、合身的身體和動作都是虛構的。**1885 年那件衣服其實是赭色的。** 下面沒有任何一個比例主張量測過的身高、體重或解剖尺寸。適度的胸部與臀部量體、成人的手和收斂的肩寬，建立起一個穿著衣服的成年身體，不做誇張。

移動用略短的步伐、小幅度的肩部反向旋轉、安靜的雙手和穩定的頭部。轉身很快定下來，腳的離地高度維持一般水準。**這些是視覺個性的權重，不改變移動速度、瞄準或武器平衡。**
